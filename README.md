# travel-journal

Онлайн-журнал «Путешествия».

## Что использовал
- HTML: заголовки, параграфы, ссылки, картинки
- CSS: фоны (фиксированные, `cover`), `min-height: 100vh`
- CSS: типографика (`text-align`, `font-size`, `line-height`, `word-spacing`, `letter-spacing`)
- CSS: отступы (`margin`, `padding`), `text-shadow`, псевдоэлемент `::before` с эмодзи
- Подключение шрифта через `@import`

## Чему научился
- Делать фиксированный фон, который не прокручивается
- Использовать `min-height` вместо `height` для длинных страниц
- Оформлять текст: выравнивание, размер, межстрочный интервал
- Добавлять эмодзи через `content` в `::before`
- Делать тени для текста, чтобы он читался на фоне
